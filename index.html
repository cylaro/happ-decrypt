01

Что это за проектWhat this project is

Локальный рабочий стол для ссылок Happ. Расшифровывает happ://crypt…crypt5 прямо в браузере (все ключи встроены), редактирует адрес подписки и её параметры, привязывает HWID к ссылке, собирает форматы импорта для клиентов и зашифровывает URL обратно через официальный API Happ. Вкладка «Запрос» отправляет запрос подписки с точными заголовками устройства и показывает ответ панели.A local workbench for Happ links. It decrypts happ://crypt…crypt5 right in the browser (all keys are bundled), edits the subscription address and its parameters, binds a HWID into the link, builds client import formats, and re-encrypts URLs through the official Happ API. The Request tab sends a subscription request with exact device headers and shows the panel response.

Спутниковые проекты: hwid-relay (релей на Cloudflare Workers) и hwid-relay-vercel (тот же релей на Vercel) — позволяют подключать много устройств так, чтобы панель видела одно.Companion projects: hwid-relay (Cloudflare Workers relay) and hwid-relay-vercel (the same relay on Vercel) — connect many devices while the panel sees one.

Рабочая область: по шагамWorkspace: step by step

  2. Отредактируйте адрес назначения и параметры. Повторяющиеся параметры сохраняются. Кнопка «hwid → в ссылку» вшивает идентификатор устройства в саму ссылку.Edit the destination URL and parameters. Repeated parameters are preserved. «hwid → into link» embeds a device identifier into the link itself.
  3. Выберите формат вывода: точный URL, Base64, JSON, импорт v2RayTun, семейство Clash, sing-box. Для телефонов — QR-код.Pick the output format: exact URL, Base64, JSON, v2RayTun import, the Clash family, sing-box. QR code for phones.
  4. При необходимости зашифруйте URL обратно в happ://crypt5 — через официальный API, после явного согласия.Optionally encrypt the URL back into happ://crypt5 — via the official API, after explicit consent.

Вкладка «Запрос»: идентичностьRequest tab: identity

Поля идентичности — x-hwid, User-Agent, x-device-os, x-ver-os, x-device-model. Правило HWID: 10–64 символа из A-Z a-z 0-9 = -. Поля сохраняются в этом браузере и автоматически переносятся в редактор.Identity fields — x-hwid, User-Agent, x-device-os, x-ver-os, x-device-model. HWID rule: 10–64 characters from A-Z a-z 0-9 = -. The fields are stored in this browser and mirrored into the editor.

Панель считает устройства по значениям x-hwid: все клиенты с одинаковым HWID для неё — одно устройство. Поэтому задайте одну идентичность и используйте её на всех устройствах, где клиент позволяет ручной ввод.The panel counts devices by their x-hwid values: every client with the same HWID is one device. Set one identity and reuse it on every device whose client supports manual input.

05

Как панель считает устройстваHow the panel counts devices

Панель (например, Remnawave) считает уникальные значения заголовка x-hwid. Значение формирует клиентское приложение — Happ, v2RayTun и другие — при каждой загрузке подписки. Два устройства с одинаковым x-hwid неотличимы для панели: они считаются одним устройством. Заголовок отправляют: Happ, v2RayTun, Koala Clash, FlClashX, Prizrak-Box, Throne, Shadowrocket, Karing, Clash Mi, Incy, RenoarX, DeskBox, Passwall-OpenWRT (у части приложений HWID по умолчанию выключен — включите в настройках).The panel (for example, Remnawave) counts unique x-hwid header values. The client app — Happ, v2RayTun and others — produces this value on every subscription load. Two devices presenting the same x-hwid are indistinguishable to the panel: they count as one device. Apps sending the header: Happ, v2RayTun, Koala Clash, FlClashX, Prizrak-Box, Throne, Shadowrocket, Karing, Clash Mi, Incy, RenoarX, DeskBox, Passwall-OpenWRT (some ship HWID disabled by default — enable it in settings).

06

Несколько устройств — одна идентичностьMultiple devices, one identity

  1. На вкладке «Запрос» задайте одну идентичность: HWID, User-Agent, модель. Поля сохраняются в этом браузере.On the Request tab set one identity: HWID, User-Agent, model. The fields are stored in this browser.
  2. Нажмите «Отправить запрос» — панель зарегистрирует идентичность и вернёт подписку.Press «Send request» — the panel registers the identity and returns the subscription.
  3. На остальных устройствах впишите тот же HWID в клиентах с ручным вводом — все они считаются одним устройством. В редакторе «hwid → в ссылку» дополнительно вшивает HWID в саму ссылку: приложение добавит её только на устройстве с этим HWID.On other devices enter the same HWID in clients with manual input — they all count as one device. In the editor, «hwid → into link» additionally embeds the HWID into the link itself: the app adds it only on a device with that HWID.

Если клиент не позволяет ввести HWID вручную, он продолжает отправлять свой собственный — и занимает отдельный слот.If a client does not allow manual HWID input, it keeps sending its own value and occupies a separate slot.

07

Если достигнут лимитWhen the limit is reached

Каждый новый уникальный HWID занимает слот. Когда слоты закончились, панель отклоняет новые идентификаторы: ответ приходит с заголовком x-hwid-max-devices-reached: true (часто с пустым телом). Это решение сервера — обойти его со стороны клиента нельзя. Варианты: удалить неиспользуемое устройство в панели, попросить владельца поднять лимит или отключить ограничение для пользователя. Использование подписки сверх условий тарифа может нарушать правила провайдера.Every new unique HWID takes a slot. Once the slots are gone the panel denies new identities: the response carries x-hwid-max-devices-reached: true (often with an empty body). This is a server-side decision and cannot be bypassed from a client. Options: remove an unused device in the panel, ask the owner to raise the limit, or disable the restriction for the user. Sharing beyond your plan may violate the provider's terms.

09

Ссылки и шифрованиеLinks and encryption

Расшифровка happ://crypt…crypt5 выполняется локально. HTTPS URL можно свободно редактировать. Для v2RayTun есть документированный импорт v2raytun://import/{subscription_link}. Crypt5-ссылку создаёт официальный API crypto.happ.su — URL отправляется туда только после вашего согласия. Base64 и JSON в списке форматов — это кодирование данных, а не конвертер конфигураций.Decryption of happ://crypt…crypt5 runs locally. HTTPS URLs can be edited freely. v2RayTun has a documented import v2raytun://import/{subscription_link}. A crypt5 link is issued by the official crypto.happ.su API — the URL is sent there only with your consent. Base64 and JSON in the format list are data encodings, not configuration converters.
